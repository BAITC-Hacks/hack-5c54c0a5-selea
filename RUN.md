# Voice Router MVP

Прототип объединяет продуктовую модель PolyAI (понимание свободной речи и маршрутизация звонка) с технической моделью Retell AI (голосовой интерфейс, workflow, actions, handoff и трассировка).

## Запуск

PowerShell:

```powershell
$env:OPENAI_API_KEY="ваш-ключ"
$env:OPENAI_MODEL="gpt-4o-mini"
python app.py
```

Откройте `http://127.0.0.1:8000`.

Без `OPENAI_API_KEY` приложение запускается в демонстрационном режиме. Этот режим нужен только для проверки интерфейса и не считается решением кейса: при оценивании должен быть включён LLM.

## Что реализовано

- маршрутизация по 40 сценариям и трём системным маршрутам;
- Structured Outputs с массивом сценариев для multi-intent;
- короткое объяснение и альтернативы для супервизора;
- состояние диалога, слоты и стек переключения тем;
- политика уверенности и передача оператору после двух неуверенных решений;
- preview необратимых действий;
- голосовой ввод и TTS через браузер;
- отображение маршрута, действий, слотов и задержки;
- одна команда запуска без установки зависимостей.

## Проверка точности

После настройки `OPENAI_API_KEY`:

```powershell
python predict_dev.py
python evaluate.py predictions.json dev_utterances.json
```

## Переменные окружения

- `OPENAI_API_KEY` — включает реальный LLM Router;
- `OPENAI_MODEL` — модель, по умолчанию `gpt-4o-mini`;
- `OPENAI_STT_MODEL` — распознавание речи, по умолчанию `gpt-4o-mini-transcribe`;
- `OPENAI_TTS_MODEL` — синтез речи, по умолчанию `gpt-4o-mini-tts`;
- `OPENAI_TTS_VOICE` — голос синтеза, по умолчанию `marin`;
- `OPENAI_BASE_URL` — базовый адрес OpenAI-совместимого Responses API;
- `PORT` — порт, по умолчанию `8000`.
